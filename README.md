# 🚖 Zuber Taxi Analysis - Análise de Dados de Táxis em Chicago

Projeto desenvolvido no bootcamp da **TripleTen** para analisar padrões de transporte urbano, identificar os principais concorrentes no mercado de táxis (como a líder *Flash Cab*), mapear os bairros de destino mais populares (como o *Loop* e o *River North*) e avaliar o impacto de fatores meteorológicos na duração das viagens.

## 🚀 Tecnologias Utilizadas
- **Python** (Pandas, Matplotlib, SciPy Stats)
- **SQL / Bases de Dados Relacionais**
- **Estatística Inferencial** (Teste T de Student / Teste de Welch para duas amostras independentes)
- **Jupyter Notebook**

## 🎯 Objetivos do Projeto
- **Exploração e Limpeza de Dados:** Carregamento de múltiplos datasets provenientes de consultas SQL, verificação de duplicados e consistência de tipos de dados.
- **Análise Exploratória (AED):** Identificação das empresas de táxi com maior volume de corridas e dos bairros de destino mais frequentes em Chicago através de gráficos de barras.
- **Teste de Hipóteses:** Validação estatística de que as condições meteorológicas (dias chuvosos vs. dias de sol) afetam significativamente a duração média das viagens entre o *Loop* e o Aeroporto Internacional *O'Hare* aos sábados.

## 💡 Principais Conclusões
A análise revelou que o mercado é fortemente liderado pela *Flash Cab*, que os destinos concentram-se esmagadoramente nas zonas financeira e comercial do centro de Chicago, e que o teste estatístico confirmou com alta significância que a chuva altera de forma mensurável o tempo de percurso, fornecendo dados cruciais para estratégias de preços dinâmicos e otimização de frota.
